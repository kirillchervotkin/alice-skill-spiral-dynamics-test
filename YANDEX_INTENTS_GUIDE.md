# Руководство по переносу интентов из Яндекс.Диалогов

## Проблема
Яндекс.Диалоги не предоставляют API для экспорта интентов, поэтому приходится копировать их вручную.

## Решение: Пошаговая инструкция

### 1. Подготовка JSON файла

Создайте файл `my-intents.json` со следующей структурой:

```json
{
  "intents": [
    {
      "name": "intent_name",
      "description": "Описание интента",
      "grammar": "root:\n  фраза 1 |\n  фраза 2 |\n  фраза 3\n\nslots:",
      "positiveTests": ["фраза 1", "фраза 2", "фраза 3"],
      "negativeTests": ["неподходящая фраза"],
      "priority": 8
    }
  ]
}
```

### 2. Копирование из Яндекс.Диалогов

Для каждого интента в консоли Яндекс.Диалогов:

1. **Название интента** → поле `name`
2. **Описание** → поле `description`  
3. **Грамматика** → поле `grammar` (копируйте как есть, с переносами строк)
4. **Положительные тесты** → массив `positiveTests`
5. **Отрицательные тесты** → массив `negativeTests`
6. **Приоритет** → поле `priority` (по умолчанию 5)

### 3. Пример из вашего скриншота

Из скриншота видно интент для желтого уровня:

```json
{
  "intents": [
    {
      "name": "spiral.describe.yellow",
      "description": "Описание желтого уровня",
      "grammar": "root:\n  опиши желтый |\n  расскажи про желтый |\n  что такое желтый |\n  про желтый |\n  о желтом |\n  желтый |\n  опиши yellow\n\nslots:",
      "positiveTests": [
        "желтый",
        "опиши желтый", 
        "расскажи про желтый",
        "что такое желтый уровень",
        "желтый цвет",
        "опиши yellow",
        "про желтый"
      ],
      "negativeTests": [
        "опиши красный",
        "расскажи про синий", 
        "что такое зеленый",
        "помощь",
        "начать тест"
      ],
      "priority": 8
    }
  ]
}
```

### 4. Конвертация в код

После создания JSON файла запустите:

```bash
npx ts-node src/utils/convert-yandex-intents.ts my-intents.json
```

Это создаст:
- `src/generated/generated-regex.controller.ts` - контроллер с методами
- `src/generated/generated-regex.controller.spec.ts` - тесты
- `src/generated/README.md` - документация

### 5. Интеграция в проект

1. Добавьте контроллер в ваш модуль:

```typescript
// app.module.ts
import { GeneratedRegexController } from './generated/generated-regex.controller';

@Module({
  controllers: [
    // ... другие контроллеры
    GeneratedRegexController,
  ],
  // ...
})
export class AppModule {}
```

2. Реализуйте логику в сгенерированных методах
3. Запустите тесты для проверки

### 6. Советы по оптимизации

- **Группируйте похожие интенты** по приоритету
- **Используйте более специфичные паттерны** для высокоприоритетных интентов
- **Тестируйте на реальных фразах** пользователей
- **Добавляйте fallback обработчики** для неопознанных фраз

### 7. Автоматизация (если возможно)

Если у вас много интентов, можно:

1. Использовать браузерные инструменты разработчика для извлечения данных
2. Написать скрипт для парсинга HTML страницы консоли
3. Использовать Selenium для автоматизации копирования

### 8. Пример полного workflow

```bash
# 1. Создаете my-intents.json вручную
# 2. Конвертируете в код
npx ts-node src/utils/convert-yandex-intents.ts my-intents.json

# 3. Добавляете в модуль и реализуете логику
# 4. Тестируете
npm test generated-regex.controller.spec.ts

# 5. Коммитите изменения
git add .
git commit -m "Add converted Yandex intents"
```

## Альтернативные инструменты

Если нужно больше интентов, рассмотрите:
- **Dialogflow** - есть экспорт/импорт
- **Rasa** - открытый исходный код
- **Microsoft Bot Framework** - хорошие инструменты разработки

Но для существующих интентов в Яндекс.Диалогах этот подход - самый быстрый способ миграции.
