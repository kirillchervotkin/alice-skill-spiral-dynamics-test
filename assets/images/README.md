# 🖼️ Изображения для карточек навыка "Спиральная динамика"

## 📋 Описание

Эта папка содержит изображения формата 16:9 (1080×608) для BigImage карточек Яндекс.Диалогов.

## 🎨 Изображения уровней спиральной динамики

| Файл | Уровень | Цвет | Описание |
|------|---------|------|----------|
| `beige_16.9.png` | Выживание | 🟤 Бежевый | Фокус на выживании |
| `purple_16.9.png` | Племенной | 🟣 Фиолетовый | Сила традиций |
| `red_16.9.png` | Силовой | 🔴 Красный | Мир-джунгли |
| `blue_16.9.png` | Порядок | 🔵 Синий | Основа — порядок |
| `orange_16.9.png` | Достижения | 🟠 Оранжевый | Двигатель прогресса |
| `green_16.9.png` | Сообщество | 🟢 Зеленый | Ценность гармонии |
| `yellow_16.9.png` | Интегральный | 🟡 Желтый | Гибкость систем |
| ~~`turquoise_16.9.png`~~ | Холистический | 🔷 Бирюзовый | ❌ Отсутствует |

## 📱 Использование

1. **Загрузите изображения** в консоль Яндекс.Диалогов
2. **Скопируйте полученные image_id**
3. **Обновите метод `getLevelImageId()`** в `src/alice/alice.controller.ts`

## 🔧 Формат

- **Разрешение:** 1080×608 пикселей
- **Соотношение сторон:** 16:9
- **Формат:** PNG
- **Размер:** до 1 МБ

## 📝 Примечания

- Изображение `image.png` - дополнительное, не относится к уровням
- Для ItemsList карточек используются квадратные изображения 200×200 (создаются через генератор)
