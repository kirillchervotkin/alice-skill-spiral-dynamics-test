# 🖼️ Настройка изображений для карточек

## 📋 Пошаговая инструкция

### **Шаг 1: Загрузка изображений в Яндекс.Диалоги**

1. Перейдите в [консоль Яндекс.Диалогов](https://dialogs.yandex.ru/developer)
2. Выберите ваш навык
3. Перейдите в раздел **"Изображения"**
4. Загрузите все 8 файлов из папки `assets/images/`:

| Файл | Описание |
|------|----------|
| `beige_16.9.png` | Бежевый уровень - Выживание |
| `purple_16.9.png` | Фиолетовый уровень - Племенной |
| `red_16.9.png` | Красный уровень - Силовой |
| `blue_16.9.png` | Синий уровень - Порядок |
| `orange_16.9.png` | Оранжевый уровень - Достижения |
| `green_16.9.png` | Зеленый уровень - Сообщество |
| `yellow_16.9.png` | Желтый уровень - Интегральный |
| `turquoise_16.9.png` | Бирюзовый уровень - Холистический |

### **Шаг 2: Копирование image_id**

После загрузки каждого изображения скопируйте полученный `image_id` (например: `937455/abc123def456`).

### **Шаг 3: Обновление кода**

Откройте файл `src/alice/alice.controller.ts` и найдите метод `getLevelImageId()` (строка ~433).

Замените заглушки на реальные ID:

```typescript
private getLevelImageId(level: string): string {
  const imageMap: Record<string, string> = {
    'beige': '937455/your-beige-id',        // ← Вставьте реальный ID
    'purple': '937455/your-purple-id',      // ← Вставьте реальный ID
    'red': '937455/your-red-id',            // ← Вставьте реальный ID
    'blue': '937455/your-blue-id',          // ← Вставьте реальный ID
    'orange': '937455/your-orange-id',      // ← Вставьте реальный ID
    'green': '937455/your-green-id',        // ← Вставьте реальный ID
    'yellow': '937455/your-yellow-id',      // ← Вставьте реальный ID
    'turquoise': '937455/your-turquoise-id' // ← Вставьте реальный ID
  };

  return imageMap[level] || '937455/your-default-id';
}
```

### **Шаг 4: Проверка**

1. Сохраните файл
2. Перезапустите навык
3. Пройдите тест до конца
4. Проверьте, что карточки отображают ваши изображения

## ✅ **После настройки**

Карточки будут показывать:
- **ItemsList** с ТОП-3 результатами и квадратными иконками
- **BigImage** с вашими красивыми изображениями 16:9 при нажатии "Подробнее"

## 🎯 **Готово!**

Навык будет полностью готов к использованию с визуальными карточками!
