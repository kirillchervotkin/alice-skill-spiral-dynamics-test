# 🌀 Spiral Dynamics Testing API

REST API для тестирования спиральной динамики Грейвза на NestJS с TypeScript.

## 🚀 Быстрый старт

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run start:dev

# Сборка проекта
npm run build
```

**Сервер запустится на:** `http://localhost:3000`  
**Swagger документация:** `http://localhost:3000/api`

## 📊 API Endpoints

### 🧪 Тесты
```
GET    /tests                    # Список доступных тестов
GET    /tests/{testId}           # Загрузка теста
GET    /tests/{testId}/exists    # Проверка существования
```

### 🌀 Спиральная динамика
```
POST   /spiral-dynamics/calculate              # Полный расчет результатов
POST   /spiral-dynamics/calculate-top3         # ТОП-3 уровня
POST   /spiral-dynamics/calculate-formatted    # Формат для Алисы
POST   /spiral-dynamics/get-full-table         # Полная таблица баллов
GET    /spiral-dynamics/levels/{level}/description  # Описание уровня
GET    /spiral-dynamics/levels/descriptions    # Все описания
```

## 🧪 Пример использования

### Получить тест:
```bash
curl http://localhost:3000/tests/spiral-dynamics-24
```

### Рассчитать результаты:
```bash
curl -X POST http://localhost:3000/spiral-dynamics/calculate-formatted \
  -H "Content-Type: application/json" \
  -d '{
    "testId": "spiral-dynamics-24",
    "answers": [
      {"questionId": "q5", "selectedOptionId": "q5_yes"},
      {"questionId": "q13", "selectedOptionId": "q13_yes"},
      {"questionId": "q21", "selectedOptionId": "q21_yes"}
    ]
  }'
```

### Ответ:
```json
{
  "announcement": "Твои ТОП – 3 уровня ценностей сейчас:",
  "top3": [
    "Первое место: Гармония/Равенство (Зеленый) - 6 баллов",
    "Второе место: Выживание (Бежевый) - 0 баллов",
    "Третье место: Магия/Племенной (Фиолетовый) - 0 баллов"
  ]
}
```

## 🎯 Алгоритм расчета

| Ответ | Баллы |
|-------|-------|
| Да | 2 балла |
| Не уверен | 1 балл |
| Нет | 0 баллов |

**Максимум:** 6 баллов на уровень (3 вопроса × 2 балла)

### Интерпретация:
- **5-6 баллов** → Доминирующий уровень
- **3-4 балла** → Вторичный уровень  
- **0-2 балла** → Слабо выражен

- **NestJS** + **TypeScript**
- **Swagger** для документации
- **Class Validator** для валидации
- **JSON** для хранения тестов

## 📝 Структура проекта

### Основные модули:
- **SpiralDynamicsModule** - расчеты и анализ результатов
- **TestsModule** - загрузка и управление тестами
- **ValidationModule** - валидация данных

### Ключевые сервисы:
- **SpiralDynamicsService** - основная бизнес-логика
- **SpiralCalculatorService** - алгоритмы расчета
- **TestsService** - работа с JSON файлами тестов
- **ValidationService** - проверка корректности данных

## 🌀 8 уровней спиральной динамики

1. **🟤 Бежевый** - Выживание (инстинкты, базовые потребности)
2. **🟣 Фиолетовый** - Племенной (традиции, ритуалы)
3. **🔴 Красный** - Сила (власть, доминирование)
4. **🔵 Синий** - Порядок (правила, иерархия)
5. **🟠 Оранжевый** - Успех (достижения, конкуренция)
6. **🟢 Зеленый** - Гармония (равенство, сообщество)
7. **🟡 Желтый** - Интеграция (системность, гибкость)
8. **🔵 Бирюзовый** - Холизм (глобальное сознание)
