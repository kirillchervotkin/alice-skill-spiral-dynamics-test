# TypeScript интерфейсы для системы тестирования спиральной динамики

Полный набор TypeScript интерфейсов для создания системы тестирования по модели спиральной динамики Клэра Грейвза.

## 📋 Описание

Этот репозиторий содержит **только интерфейсы и типы данных** для системы тестирования спиральной динамики. Интерфейсы определяют полный контракт для профессиональной системы оценки 8 уровней спиральной динамики.

## 🎯 Зачем нужна система тестирования спиральной динамики?

**Спиральная динамика** - это психологическая модель развития человеческого сознания по Клэру Грейвзу, которая помогает понять, как люди думают, принимают решения и что их мотивирует.

## 🎯 8 уровней спиральной динамики

| Уровень | Цвет | Код | Описание |
|---------|------|-----|----------|
| 1 | Бежевый | AN | Выживание: базовые потребности, инстинкты |
| 2 | Фиолетовый | BO | Племенной: традиции, ритуалы, принадлежность |
| 3 | Красный | CP | Силовой: власть, импульсы, доминирование |
| 4 | Синий | DQ | Порядок: правила, иерархия, дисциплина |
| 5 | Оранжевый | ER | Достижения: успех, конкуренция, инновации |
| 6 | Зеленый | FS | Гармония: равенство, сообщество, эмпатия |
| 7 | Желтый | GT | Гибкость: системность, интеграция, адаптивность |
| 8 | Бирюзовый | HU | Целостность: глобальное сознание, холизм |

## 📁 Структура интерфейсов

- **`spiral-levels.enum.ts`** - Enum уровней и метаданные

### Интерфейсы сервисов (`src/services/interfaces/`)

- **`test-service.interface.ts`** - Главный сервис тестирования
- **`spiral-calculator.interface.ts`** - Алгоритмы расчета результатов
- **`test-provider.interface.ts`** - Управление тестовыми данными

## 📊 Алгоритм подсчета

### Система оценки
- **Да** = 2 балла
- **Не уверен** = 1 балл
- **Нет** = 0 баллов

### Группировка вопросов
Каждый уровень оценивается по 3 вопросам (максимум 6 баллов):
- Бежевый: вопросы 1, 9, 17
- Фиолетовый: вопросы 2, 10, 18
- Красный: вопросы 3, 11, 19
- И так далее...
